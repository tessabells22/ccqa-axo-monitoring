      Import AXO CSV

      Use the items export from AXO. New AXOs are added; existing ones get their AXO fields refreshed.

      Drop the CSV here or click to choose Item Type is mapped on import: defects → Bug, features → User Story
      Your QA work is safe. Status, handler, system, comments and notes are never overwritten by an import.

      Add an AXO by hand

      For items that aren't in an export yet. The next import fills in the AXO fields.

      Who's making this change?

      Pick your name before changing anything in the tracker. Every edit, note and import is signed with it. The tracker remembers it on this browser.

      Set status

      Every selected AXO moves to this status. Review Points isn't here: points are written for one AXO at a time.

      Set release

      Type the release number only, for example 5.4. ERPIS or SERPCAR is added from each AXO's category when the email is drafted.

      Leave it empty to clear the release on these AXOs.

      Delete AXOs

      They leave the tracker and move to the Deleted tab of the Google Sheet, where they can be restored. Their notes are kept.
